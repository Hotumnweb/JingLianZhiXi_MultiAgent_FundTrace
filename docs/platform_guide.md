## 一、平台定位

第一台电脑是**调度中心**，不运行大模型、不运行图数据库，只负责：

1. 运行 LangGraph Supervisor / 编排器，作为元智能体的“大脑”；
2. 作为前端入口，评委看到的所有“下发任务 / 查看结果”操作都在这里；
3. 管理集群状态：任务队列、子智能体调用日志、中间结果汇总。

平台把“接口、数据、智能体、报告、日志”集成到一个界面，操作感和展示效果优先。

## 二、页面说明

### 1. 调度总览

- 数据分析 KPI：交易流水、图账户节点、可疑账户、归集、环形链、快进快出；
- 三节点集群卡：Node1 调度 / Node2 GPU（占位）/ Node3 工具与图数据；
- 图规则命中分布与证据强度排行；
- 最近一次研判摘要。

讲解要点：**“第一台只调度，不跑模型和图库；算力在 Node2，数据工具在 Node3。”**

### 2. 元智能体调度

- 数据源选择（Node3 读取）、自定义路径、侦查任务描述；
- 开关 AI 研判报告（调用 Node2 GPU：qwen3.5-9b-tools:q4km）；
- **提交到任务队列**或**立即执行**；
- 下发任务后：阶段卡实时点亮、调度日志滚动、AI 报告逐 token 输出；
- 完成后展示可疑账户、证据构成、报告与证据下载；可继续下发**追加侦查指令**；
- 页面顶部明确写出调用链：Node1 → Node2（Qwen3.5-9B-tools + Qwen-Agent）↔ Node3。

讲解要点：**“下发一次任务，元智能体拆解、调用工具、汇总结果，第一台负责调度和记录。”**

### 3. 任务队列

- 队列状态：排队中 / 执行中 / 已完成 / 失败；
- 执行队列：按顺序执行排队任务；
- 任务详情：调度步骤、Node1/Node2/Node3 调用记录、中间结果（解析条数、图谱规模、证据数量）；
- 支持任务重跑；任务记录持久化在 `runtime/tasks/`。

讲解要点：**“第一台维护任务队列和集群状态，评委可以看到每个任务被调度到哪个节点、执行了多久。”**

### 4. 数据资产

- `data/new/` 大数据集目录：IBM AML HI/LI、PaySim、Elliptic、IEEE-CIS，卡片展示规模、标签、许可与推荐用途；
- 一键生成确定性抽样（`data/prepared/`）；点“在调度页使用”直接带着样本跳转；
- 样本预览（统一中文流水前 20 行）、IBM 8 类洗钱模式清单；
- 抽样样本规则评测：在当前图谱上复算精确率/召回率与 IBM 模式覆盖；
- 赛场展示路线（8 分钟版）与现场注意事项。

讲解要点：**“真实规模数据不进 Git、不现场扫描；抽样一键生成，换数据源不改代码。”**
详见 [DATASET_GUIDE.md](DATASET_GUIDE.md)。

### 5. 数据接入

- 真实一手数据接入：服务器文件直读（几百 MB 无需上传）或上传小文件；
- 自动画像：编码（UTF-8/GBK/GB18030/Big5）、分隔符（逗号/分号/Tab/竖线）、表头、行数、列画像；
- 字段映射：自动建议 + 手工调整；支持“银行号+账号”复合账号、多格式时间（字符串/Unix/步长）、￥金额；
- 流式清洗：分块读取（20 万行/块），选行数上限与抽样方式，实时进度；
- 清洗产物：统一中文流水 + `_stats.json` 清洗报告（剔除原因可追溯），可直接跳转建图；
- pandas 分析台：金额分布、按日趋势、Top 账户与受限 pandas 表达式查询。

讲解要点：**“公安拿到的一手数据就是乱 + 大：平台现场自动识别、流式清洗、马上建图，不用先回去手工整理。”**
详见 [DATA_CLEANING_GUIDE.md](DATA_CLEANING_GUIDE.md)。

### 6. 图数据与工具

- Node3 Neo4j 子图：归集账户（紫）、环形账户（金）、快进快出（蓝）、邻居（灰）；
- 环形链、归集账户明细、证据强度排行；
- 附 Neo4j 复核 Cypher。

讲解要点：**“账户是点、转账是线，图工具把水房和环形流转直接画出来。”**

### 7. 规则与指标

- 三条规则口径与当前命中；
- 现场重算精确率、召回率、F1、团伙级召回；
- 数据集画像（交易量、账户、团伙类型）。

讲解要点：**“规则在 Node3 执行，标签只用于评测，不进入智能体决策。”**

### 8. 研判报告

- 历史报告列表、Markdown 预览、报告/证据下载；
- 证据明细（归集/环形/快进快出）。

讲解要点：**“每份报告都有证据 JSON 配套，可复核、可复现。”**

### 9. 节点与工具

- 三节点状态与网络规划；
- 接口与工具清单；
- Node2 当前状态（IP 192.168.0.200，qwen3.5-9b-tools:q4km，think=false）；
- Node3 工具说明（Neo4j / pandas / 可选嵌入模型）；
- 调度日志、断网自检、现场检查清单。

讲解要点：**“Node1 调度、Node2 算力、Node3 工具，三机职责清晰。”**

- 页面：左侧“Neo4j 操作台”；
- 页面顶部显示当前连接地址（`.env` 的 `NEO4J_HOST` + `NEO4J_PORT`，本机回环 `127.0.0.1:7687`）；

## 七、元智能体自主分析（工具调用实验台）

- 页面：左侧“元智能体自主分析”；
- 流程：Node2 Qwen3.5-9B-tools 读取任务 → 自主选择工具 → Node1/Node3 执行 → 结果回传 → 模型继续决策或总结；

- 工具：图谱规模、归集查询、快进快出查询、账户资金往来、证据摘要、规则指标；
- 与“元智能体调度”的区别：调度页是稳定的固定 Supervisor 流水线；自主分析页是真正的 tool-calling 实验台。
