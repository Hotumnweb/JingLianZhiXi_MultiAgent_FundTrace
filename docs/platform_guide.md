# 集成展示平台使用说明（第一台电脑 · Controller）

> 启动：`streamlit run app.py`（默认 <http://localhost:8501>）
> 平台版本：v0.4 集成展示平台
> 适用：第一台电脑（核心调度与编排工作台），当前单机联调模式下同时承载 Neo4j 与本地 Ollama。

---

## 一、平台定位

第一台电脑不再只是“跑代码的机器”，而是整个比赛的**控制与展示中心**：

- 对评委：一屏看懂“数据从哪来、智能体在干什么、图计算发现了什么、大模型写出了什么报告”；
- 对队员：一个入口完成数据源选择、全链路启动、证据复核、报告下载、节点自检；
- 对答辩：内置演示脚本、指标复算、断网自证、审计事件流，讲解时“有东西可点、有数据可看”。

## 二、页面说明

### 1. 作战总览

- 六项 KPI：交易流水、图账户节点、可疑账户、团伙命中、强证据精确率、本地推理速度；
- 四节点拓扑卡：Node1 调度 / Node2 推理 / Node3 图数据与审计 / Node4 演示终端，
  显示在线状态、地址、延迟、模型或图谱规模；
- 图规则命中分布 + 证据强度排行；
- 最近一次研判摘要（案件编号、可疑账户、耗时、tok/s）。

讲解要点：**“四个节点各司其职，平台能实时看到每个节点是否在线。”**

### 2. 智能体编排

- 选择数据源（AML 完整数据集 / 100 条演示数据）或输入自定义 CSV 路径；
- 输入侦查指令，勾选是否启用大模型报告；
- 点击“启动全链路分析”后：
  - 四张阶段卡（主控调度 → 流水解析 → 账户关联 → 研判报告）实时点亮；
  - 右下角日志实时滚动（解析条数、建图规模、规则命中、报告生成）；
  - 报告内容**逐 token 流式出现**，而不是黑屏等待；
- 完成后显示 KPI、完整报告、报告/证据下载按钮、可疑账户清单与完整日志。

讲解要点：**“评委看到的不是等待，而是智能体流水线在运行。”**

### 3. 资金图谱

- 从 Neo4j 拉取可疑账户的 1 跳子图；
- 不同颜色区分：归集账户（紫）、环形转账账户（金）、快进快出账户（蓝）、关联邻居（灰）；
- 右侧展示环形转账链、归集账户明细；下方是证据强度排行表；
- 可关闭“显示关联邻居”只看强证据账户；附 Neo4j Browser 复核查询。

讲解要点：**“账户是点、转账是线，图计算把‘水房’和‘环形流转’直接画出来。”**

### 4. 规则与指标

- 三条规则卡片：判定口径 + 证据等级；
- 当前命中数量；
- 点击“重新计算检测指标”，现场执行规则并读取数据集标签计算：
  - 各规则/强证据合并/最终清单的精确率、召回率、F1；
  - 团伙级召回（22/22）；
- 数据集画像（交易量、账户数、团伙类型、金额规模）。

讲解要点：**“标签只用于事后评测，智能体看不到答案——这是我们主动做的防标签泄漏设计。”**

### 5. 报告中心

- 历史报告列表（案件编号、生成时间、可疑账户、耗时、tok/s、大模型/规则兜底）；
- 报告 Markdown 预览；
- 下载研判报告与证据 JSON；
- 证据明细（归集账户 / 环形链 / 快进快出）表格。

讲解要点：**“每份报告都有配套证据 JSON，可复核、可复现。”**

### 6. 节点与安全

- 四节点健康状态与规划 IP；
- 本机环境（CPU、内存、内网地址、Python）；
- **检测外网连通性（断网自证）**：现场拔网后点击，显示“外网不可达”；
- 接口集成清单（LangGraph / Bolt / Ollama / pandas / 报告 / 审计 / Streamlit）；
- 审计事件流（分析开始/结束/失败、外网检测、评测记录），对应第三台审计节点；
- 第三台 Wireshark 接入说明与现场检查清单。

讲解要点：**“数据不出局、算力本地闭环，审计日志和抓包共同证明这一点。”**

## 四、演示前 60 秒自检

```powershell
conda activate fraud_agent
cd /d E:\JingLianZhiXi_MultiAgent_FundTrace
python scripts/preflight_check.py
streamlit run app.py
```

- 刷新节点状态：四个节点都应为在线（Node2 本地 CPU / GPU，Node3 Neo4j）；
- 报告中心应有至少一份报告；
- 断网自证按钮应显示“外网不可达”；
- 若现场 GPU 节点临时故障：在 `.env` 把 `OLLAMA_BASE_URL` 改回 `127.0.0.1`，
  或在编排页直接点“仅跑图分析”，仍可完整展示图计算与可疑账户。

## 五、四机部署后的变化

| 页面 | 当前（单机联调） | 四机部署后 |
| :--- | :--- | :--- |
| 节点状态 Node2 | 本机 Ollama（CPU） | 第二台 GPU 节点（192.168.50.2） |
| 节点状态 Node3 | 本机 Neo4j | 第三台图数据库 + 审计节点（192.168.50.3） |
| 节点状态 Node4 | 当前浏览器 | 第四台 HDMI 大屏（192.168.50.4） |
| 审计事件流 | 本地 JSONL | 叠加 Wireshark 镜像抓包证据 |
| 报告生成耗时 | 约 2~4 分钟（CPU） | 预计数十秒（GPU） |

平台代码不需要改动，只改 `.env` 的地址即可。
