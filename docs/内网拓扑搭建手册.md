# 警链智析内网拓扑搭建手册（eNSP 练习 + 神州数码真机）

> 适用：2027 甘肃省职业院校技能大赛 · 网络攻防赛项  
> 场地约束：**不提供外网，只搭内网**。  
> 可用设备：防火墙、二层交换机、三层交换机、无线 AC（AP 视现场情况）；其他 WAF/堡垒机/行为管理/沙箱**已损坏，不接入**。  
> 目标：拓扑有层次、能体现 VLAN/VRRP/MSTP/链路冗余/防火墙策略，但半个月内能练熟、能上真机。

---

## 0. 最终拓扑一览

### 0.1 设备角色

| 名称 | 实际设备 | 角色 |
|---|---|---|
| CORE-1 | CS6200-28X-Pro | 三层核心，VRRP 主 |
| CORE-2 | CS6200-28X-Pro | 三层核心，VRRP 备 |
| ACC-1 | S5750E | 平台/算力/数据接入 |
| ACC-2 | S5750E | 预留扩展/第二平台区 |
| ACC-3 | S4600 | 演示/管理/无线/防火墙接入 |
| FW-1 | DCFW-1800（8 个 GE 口） | 演示区到内网的唯一防火墙 |
| AC | DCWS-6028-C | 无线管理 |
| AP | WL8200-I2（若可用） | 演示无线 |
| 笔记本 ×4 | 通用 | 平台-A/B/C、主讲/演示 |

### 0.2 逻辑拓扑

```text
                       CORE-1 ====== CORE-2
                         |  \        /  |
                         |   \      /   |
                       ACC-1  ACC-2  ACC-3
                         |      |      |
              Platform-A/B/C  预留   主讲PC / AP / AC
              Node2 / Node3           |
                                      FW-1
                                      |
                                 内网无外网
```

更具体：

```text
CORE-1 ── 直连 Trunk/LACP ── CORE-2
  │  \                         /  │
  │   \                       /   │
ACC-1  ── 双上行 MSTP ── ACC-2  ACC-3
  │                            │
  ├─ Platform-A 10.20.10.11    ├─ 主讲PC VLAN40
  ├─ Platform-B 10.20.10.12    ├─ AP / AC
  ├─ Platform-C 10.20.10.13    └─ FW-1（e0/0 演示、e0/1-2 Transit、e0/3 MGMT）
  ├─ Node2 10.20.20.20
  └─ Node3 10.20.30.30
```

### 0.3 关键设计点

1. **无外网**：不画 Cloud、不配默认路由、不做 NAT。
2. **双三层核心**：CORE-1/CORE-2 做 VRRP，平台/算力/数据网关有冗余。
3. **双上行接入**：ACC-1/2/3 同时接 CORE-1/CORE-2，用 MSTP 防环。
4. **防火墙只做演示区边界**：主讲区 -> FW-1 -> 平台区；不能直接访问 AI/数据。
5. **平台区预留 3 个口**：Platform-A/B/C；现在先用 A，后续拆分平台和新增平台直接上 B/C。
6. **管理面独立**：VLAN99，交换机/防火墙/AC/AP 管理地址都在这里。
7. **不再画 WAF/NTA/沙箱/堡垒机**：它们已经坏了，画上去只会扣分。

## 3. eNSP 搭建步骤

### 3.1 建图

1. 打开 eNSP，新建拓扑。
2. 放置设备：
   - 2 台三层交换机：S5700/S5720，命名 `CORE-1`、`CORE-2`；
   - 3 台二层交换机：S5700 或 S3700，命名 `ACC-1`、`ACC-2`、`ACC-3`；
   - 1 台防火墙：USG6000V，命名 `FW-1`；
   - 1 台 AC、1 台 AP（若 eNSP 支持）；
   - 4 台 PC：`Platform-A`、`Platform-B`、`Node2`、`Node3` 或按实际命名。
3. 不要放 Cloud/Internet；本场景无外网。
4. 按第 2 节连线；核心-接入用光纤/GE，PC 用铜线。

### 3.2 先配核心，不接业务

先关闭所有接入交换机的业务口，只保留管理口，避免一上来就环路。

#### CORE-1 基础

```text
system-view
sysname CORE-1
vlan batch 10 20 30 40 99 100
stp mode mstp
stp instance 0 root primary
```

#### CORE-2 基础

```text
system-view
sysname CORE-2
vlan batch 10 20 30 40 99 100
stp mode mstp
stp instance 0 root secondary
```

#### 核心互联 Trunk

以 CORE-1 为例，CORE-2 对称配置：

```text
interface Eth-Trunk1
 port link-type trunk
 port trunk allow-pass vlan 10 20 30 40 99 100
interface GigabitEthernet0/0/23
 eth-trunk 1
interface GigabitEthernet0/0/24
 eth-trunk 1
```

> eNSP 的端口编号按你实际连线改；核心互联也可以不做 LACP，先用单链路，稳定后再加。

### 3.3 核心 VLAN 网关 + VRRP

CORE-1：

```text
interface Vlanif10
 ip address 10.20.10.252 24
 vrrp vrid 10 virtual-ip 10.20.10.1
 vrrp vrid 10 priority 120
interface Vlanif20
 ip address 10.20.20.252 24
 vrrp vrid 20 virtual-ip 10.20.20.1
 vrrp vrid 20 priority 120
interface Vlanif30
 ip address 10.20.30.252 24
 vrrp vrid 30 virtual-ip 10.20.30.1
 vrrp vrid 30 priority 120
interface Vlanif99
 ip address 10.20.99.252 24
 vrrp vrid 99 virtual-ip 10.20.99.1
 vrrp vrid 99 priority 120
interface Vlanif100
 ip address 10.20.100.252 24
 vrrp vrid 100 virtual-ip 10.20.100.1
 vrrp vrid 100 priority 120
```

CORE-2：同样创建 Vlanif，IP 改 `.253`，**priority 默认 100**（不写 priority 即可）。

检查：

```text
display vrrp brief
display stp brief
```

CORE-1 应为 Master，CORE-2 为 Backup；MSTP 中 CORE-1 为根桥。

### 3.4 接入交换机

#### ACC-1

```text
system-view
sysname ACC-1
vlan batch 10 20 30 99
interface GigabitEthernet0/0/23
 port link-type trunk
 port trunk allow-pass vlan 10 20 30 99
interface GigabitEthernet0/0/24
 port link-type trunk
 port trunk allow-pass vlan 10 20 30 99
```

业务口：

```text
interface GigabitEthernet0/0/1
 port link-type access
 port default vlan 10
 stp edged-port enable
interface GigabitEthernet0/0/2
 port link-type access
 port default vlan 10
 stp edged-port enable
interface GigabitEthernet0/0/3
 port link-type access
 port default vlan 10
 stp edged-port enable
interface GigabitEthernet0/0/4
 port link-type access
 port default vlan 20
 stp edged-port enable
interface GigabitEthernet0/0/5
 port link-type access
 port default vlan 30
 stp edged-port enable
```

ACC-2 按同样方式配双上行，业务口先关闭；ACC-3 配 VLAN40/99/100 和对应接入口。

### 3.5 防火墙

#### 接口

```text
system-view
sysname FW-1
interface GigabitEthernet1/0/0
 ip address 10.20.40.1 24
interface GigabitEthernet1/0/1
 ip address 10.20.100.2 24
interface GigabitEthernet1/0/3
 ip address 10.20.99.2 24
```

> eNSP 的 USG 接口名可能是 `GigabitEthernet1/0/0` 或 `GigabitEthernet0/0/0`，按实际改；真机 DCN 的接口名以面板 e0/0～e0/7 为准。

#### 路由

无外网，不配默认路由：

```text
ip route-static 10.20.10.0 255.255.255.0 10.20.100.1
ip route-static 10.20.20.0 255.255.255.0 10.20.100.1
ip route-static 10.20.30.0 255.255.255.0 10.20.100.1
```

> 10.20.99.0/24 是 FW-1 e0/3 的直连网段，不需要再写静态路由。

核心侧需要回程路由：

```text
ip route-static 10.20.40.0 255.255.255.0 10.20.100.2
```

#### 安全区域

- e0/0 → DEMO 区
- e0/1-2 → TRANSIT 区
- e0/3 → MGMT 区
- 没有 WAN/UNTRUST 区，因为无外网。

#### 安全策略

1. DEMO → PLATFORM：只允许 `10.20.10.11/12/13` 的 8501/8502，拒绝其他。
2. DEMO → AI/DATA：拒绝。
3. MGMT → 所有设备管理口：允许，但只限管理 VLAN。
4. PLATFORM → AI：Node1 到 `10.20.20.20:11434`；PLATFORM → DATA：`10.20.30.30:7687/7474`；这些流量走核心 VLAN 间路由，不一定经过防火墙；必须在 CORE 上配 ACL。
5. 不配 NAT；不配默认路由。

#### DHCP（演示区）

- 在 FW-1 VLAN40 上开 DHCP，地址池 `10.20.40.100-199`。
- 网关 `10.20.40.1`，DNS 可留空或用平台地址。
- AP 用静态 `.2`。

### 3.6 无线/AP（有则做，没有则跳过）

- AC：`10.20.99.11`
- AP：`10.20.99.12`
- SSID：`JZ-Demo`，映射 VLAN40
- AP 接 ACC-3 2 口，PoE 模块供电
- 开启客户端隔离
- 无线只能访问平台地址，不能访问 AI/DATA

### 3.7 平台地址

| 设备 | IP | 网关 | 端口 |
|---|---|---|---|
| Platform-A | 10.20.10.11/24 | 10.20.10.1 | 8501 |
| Platform-B | 10.20.10.12/24 | 10.20.10.1 | 8501/8502 |
| Platform-C | 10.20.10.13/24 | 10.20.10.1 | 8501 |
| Node2 | 10.20.20.20/24 | 10.20.20.1 | 11434 |
| Node3 | 10.20.30.30/24 | 10.20.30.1 | 7687/7474 |
| 主讲 | DHCP 10.20.40.x | 10.20.40.1 | 浏览器访问平台 |

> 平台 `.env` 里的 Neo4j 连接地址是 **IP + 端口** 两项：
> `NEO4J_HOST=10.20.30.30`、`NEO4J_PORT=7687`（联调本机时改回 `127.0.0.1` + `7687`）。
> 改完用 `python scripts/check_neo4j.py` 验证连通性。

## 4. 核心 ACL（没有 WAF，靠核心交换机限制）

在 CORE-1/CORE-2 上配置（eNSP 语法示意，真机按 DCN 调整）：

```text
acl number 3000
 rule 10 permit tcp source 10.20.10.0 0.0.0.255 destination 10.20.20.20 0 destination-port eq 11434
 rule 20 permit tcp source 10.20.10.0 0.0.0.255 destination 10.20.30.30 0 destination-port eq 7687
 rule 30 permit tcp source 10.20.10.0 0.0.0.255 destination 10.20.30.30 0 destination-port eq 7474
 rule 40 deny ip source 10.20.10.0 0.0.0.255 destination 10.20.20.0 0.0.0.255
 rule 50 deny ip source 10.20.10.0 0.0.0.255 destination 10.20.30.0 0.0.0.255
```

规则写完后，在 CORE-1/CORE-2 的 Vlanif10 入方向应用 ACL：

```text
interface Vlanif10
 traffic-filter inbound acl 3000
```

> 上面规则只是示意，实际 ACL 需要先 permit 平台到 Node2/Node3 的必要端口，再 deny 其他。  
> 没有防火墙保护内部 VLAN 时，核心 ACL 必须写清楚：平台只能访问 Node2 的 11434、Node3 的 7687/7474，其他一律拒绝。

| 主讲访问 Platform-A 8501 | 通 |
| 主讲访问 Node2 11434 | 不通 |

### 5.3 冗余

1. 在 CORE-1 上关闭 Vlanif10 或断开 CORE-1 上行；
2. 在 Platform-A 上持续 ping 网关 `10.20.10.1`；
3. 期望短暂中断后恢复，VRRP 切换到 CORE-2；
4. `display vrrp` 在 CORE-2 上看到 Master。

### 5.4 MSTP

```text
display stp brief
```

确认 ACC-1/2/3 到两个核心的端口中，有且只有一个转发，另一个阻塞；不要出现双转发环路。

## 6. 真机迁移步骤

### 6.1 先备份

- 每台交换机、防火墙导出配置文件；
- 记录原管理 IP、VLAN、端口；
- 拍照记录每根线：本端端口 → 对端设备/端口。

### 6.2 线缆和标签

建议标签格式：

```text
CORE1-G0/0/1  ->  ACC1-25
CORE1-G0/0/2  ->  ACC1-26
FW1-e0/0      ->  ACC3-4
```

颜色建议：

- 红色：核心/上行
- 蓝色：业务接入
- 黄色：管理
- 绿色：无线/AP

### 6.3 配置顺序

1. 先配 CORE-1，再配 CORE-2；只配 VRRP/MSTP，不接业务口。
2. 配 ACC-1，先只接一台测试 PC，验证 VLAN10。
3. 配 ACC-3，接 FW-1，验证演示区到平台。
4. 配 ACC-2，保留扩展。
5. 最后接 AP/AC，开无线。
6. 每完成一步，保存配置并测试，不要一次全配完。

### 6.4 DCN 真机注意

- DCN 的 CLI 和 eNSP 华为语法不完全一样；以设备 Web 管理页面/命令手册为准；
- 先在 eNSP 练**逻辑和地址**，真机只做等价配置；
- 真机第一次配置用 Console 线，不要只依赖网络登录；
- 改 VRRP/MSTP 前先备份，避免环路导致全断；
- 管理 VLAN99 不要从业务口直接放行。

## 8. 最后提醒

- 这版**没有 WAF、堡垒机、沙箱、NTA**，它们已经损坏，不要画、不要配。
